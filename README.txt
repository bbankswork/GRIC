GRICPD website prototype
------------------------
1. Unzip and keep every file together in this folder.
2. Open gricpd-homepage-mockup.html in Chrome (not inside a preview window),
   then click around using the menu.
3. Photos load from the shared Google Drive folder, so you need an internet connection.
4. Header videos: see videos/PUT-VIDEOS-HERE.txt.

Every page in the sitemap is built (31 pages):
- Home
- About: About Us, Mission, Leadership, Fallen Officers, Gila River Indian Community
    (Community sub-pages, linked from that page: Citizens Police Academy, Ride Along, Neighborhood Block Watch, GRPD Mobile App, Coffee with a Cop)
- Join the Team: Application Requirements (Join the Team overview) > Cadet Program
- Services: Patrol, Traffic, K-9 Unit, School Resource Officer, Rangers
- Crime Prevention: Neighborhood Watch, Vacation House Checks, Sex Offender Info, Blue Envelope Program, Emergency Alert Sign-Up
- Online Forms: Property & Evidence, Records Requests, Commendations & Complaints, Police Community Request
- News: GRIC Police News (+ sample article: gricpd-news-post.html), Missing Persons (live Facebook feed)
- Contact
Only the Privacy Policy and Terms of Use links open a "page in progress" placeholder.
Forms are prototypes: they check required fields but nothing is sent.
